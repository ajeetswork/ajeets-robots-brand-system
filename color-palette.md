# Ajeets Robots – Color Palette

## Product Color Confusion Risks

Documented from Printify variant audit – see `product-naming-conventions.md`, `ajeets-robots-store-qa/variant-review-checklists.md`, and `ajeets-robots-product-research/printify-variant-audit-2026-08.md`.

### Men's Soft Shell Jacket (Printify ID 6a5167f5667e100da0023814)

- 6 colors × 9 sizes = 54 variants
- **Risk:** Navy vs Royal vs Charcoal look similar in mockups
- **Fix:** Always include hex codes + provider swatch references in product listings

### Ajeet Robot mens tee (Printify ID 6a51683a667e100da0023852)

- 19 colors × 10 sizes = 190 variants
- **Risk:** Heather Grey / Athletic Heather / Sport Grey confusion
- **Fix:** Color swatch callouts with hex codes

### Kids Cotton Tee (Printify ID 6a51687e667e100da0023895)

- 12 colors × 11 sizes = 132 variants
- **Risk:** 12 similar color names, high confusion risk
- **Fix:** Prominent size chart + color swatch callouts

## Recommendation

Always include hex codes + provider swatch references in product listings to prevent color-confusion returns.
